# How to Preview or Download the Ladnut Storefront Deck

The ChatGPT/Codex **Diff** panel does not render binary assets. If you click the PDF or PNG files in that panel, it can show `Binary files are not supported` or `Binary file not shown`. That message is a UI limitation, not a broken deck.

## What changed to make PR preview possible

To avoid the Create PR flow being blocked by binary files, the repository now keeps the deck preview assets in text-based SVG form:

- Editable source deck: `Ladnut Storefront Visual Layout.html`
- Renderer: `scripts/render_deck.py`
- PR-friendly preview pages: `previews-svg/page-01.svg` through `previews-svg/page-14.svg`

The generated PDF and PNG files are intentionally ignored by git because the current PR interface cannot display or submit binary files reliably.

## How to preview in the PR / browser

After creating the PR, open these SVG files in GitHub or download them from the repository:

```text
previews-svg/page-01.svg
previews-svg/page-02.svg
...
previews-svg/page-14.svg
```

SVG is text-based, so it is much more compatible with PR review tools than PDF or PNG.

## How to generate the final PDF locally

Run this command from the repository root:

```bash
python scripts/render_deck.py
```

That command regenerates:

```text
Ladnut Storefront Visual Layout.pdf
previews/page-01.png through previews/page-14.png
previews-svg/page-01.svg through previews-svg/page-14.svg
```

Then open `Ladnut Storefront Visual Layout.pdf` locally with a PDF reader.

## Why the PDF is not committed now

The requested PDF is still generated by the renderer, but it is not committed to the branch because the current Create PR / Diff interface reports binary files as unsupported. Keeping the PDF out of git allows the PR to be created and reviewed while preserving an easy one-command PDF build.
